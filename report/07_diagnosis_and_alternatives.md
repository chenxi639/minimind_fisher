# 冻结诊断、本轮方案总结与备选路线

日期：2026-09-30。结论：本轮“中层全前缀K8 Fisher残差”可训练，但未获得相对纯MiniMind的净收益。
建议将当前方案作为已完成的首轮探索归档，不升级为默认模型，不直接扩大其训练预算。
本轮只读取已训练权重，优化更新0次；测试集未用于评估或选择。

## 1. 本轮方案与证据链

任务：将视觉Fisher编码思想插入MiniMind，并通过对照验证效果。
顺序已完成：纯基线训练/测试 → 独立候选实现与功能验证 → 受控成对训练 → 冻结诊断。

候选：原版64M dense，768维/8层，第4块后接RMSNorm、64维投影、8成分简化Fisher；
一/二阶统计按因果前缀累计，平滑幂归一化+L2，再由零初始化线性投影残差接回。
训练：同骨干初值、数据顺序、seed42、16384条文本、长度340、1轮1024次更新，
每组4176264有效训练token；开发集1024条/265051有效预测token。
参数增加837376（1.31%），本次完整运行计时增加7.4%，峰值allocated增加35.56MiB。
本轮不含GMM、SFT或RL。

已证实：因果性、掩码、缓存一致性、零扰动、梯度流、保存重载等功能检查通过；
两组初始开发CE一致；逐更新token暴露一致；训练正常完成。
未证实：跨种子稳定收益、容量收益与统计收益的区别、最终测试集表现及生成质量提升。

## 2. 冻结诊断结果

使用与训练阶段相同的开发集、BF16和原版loss汇总路径，无参数更新。
统计只计入产生有效next-token标签的位置，不让padding或最后一个无预测位置影响结果。

| 模型/诊断模式 | 开发CE | PPL |
|---|---:|---:|
| 独立训练纯MiniMind（上一轮） | 4.236217764 | 69.14583077 |
| Fisher正常启用（本轮精确复测） | 4.239570245 | 69.37802986 |
| 同一个Fisher模型关闭残差 | 4.240320931 | 69.43013055 |

正常启用结果与原记录完全一致。
关闭残差CE上升0.000750686，PPL约上升0.075%；相对独立纯模型，Fisher正常启用仍
高0.003352481 CE、0.3358% PPL。这两种差值不可作可加的因果归因：
关闭分支的骨干是联合训练后的骨干，并非独立纯模型。
结论是“联合训练模型对分支有轻微依赖，但整体没有赢过纯基线”，不是“分支完全无用”。

| 机制统计 | 结果与解释 |
|---|---|
| 平均逐token残差/主干L2范数比 | 1.5653% |
| 整体残差/主干L2范数比 | 1.4662% |
| 平均分配熵 | 2.071285 nats |
| 均匀K8分配最大熵 | ln(8)=2.079442 |
| 平均最大成分分配 | 0.15031；均匀参考为0.125 |
| 各成分平均占用 | 11.57%—14.21% |
| 平均占用熵对应有效成分数 | 7.983/8 |

占用均衡与逐token高熵共同表明本开发集上的分配接近均匀；
有效成分数接近8不等于8个成分学到了独立语义。没有单一成分占据全部质量的现象，
也不能把高熵本身断言为错误，软分配本来就可能较分散。
残差小不必然无效；结合关闭实验，只能说观测到的边际帮助很小。

参数变化确认分支并非始终零输出：相对初始值的L2变化，
w约0.2630，b约0.1656，输入投影约2.0214，输出投影约7.8330。
checkpoint的SHA256在诊断前后相同，权重没有被改写。

## 3. 哪些解释成立，哪些仍是假设

成立：当前配置在三个训练后开发检查点均未超过baseline；额外分支实际参与计算且参数已变化；
开发集成分区分较弱；训练和测试管线正常，未出现已知数值故障。

假设：近均匀成分可能造成重复统计、全前缀平均可能稀释近期信息、
从零变化的特征空间可能不利于学出成分结构、短预算或seed波动可能掩盖小收益。
本轮未分别操纵这些因素，不能把其中任何一项宣布为失败原因。

原始[Deep FisherNet论文](https://arxiv.org/abs/1608.00182)讨论视觉局部描述子聚合与
物体分类，并不能作为此语言模型前缀改造必然有效的证据。
本项目是跨任务适配研究，阴性结果也是有效产出。

## 4. 备选及执行优先级（均未执行）

以下是本项目的实验提案，不是已有数据支持的最优方案。每次只改一个核心因素，
新建配置快照，不覆盖本轮；不同时开展所有路线。

| 优先级/备选 | 要回答的问题 | 最小改动与预算 | 判定 |
|---|---|---|---|
| 1：K=1的一/二阶前缀统计 | 多成分编码是否多余？ | 保持索引3、D64、初始化原则和同数据预算，仅K改1，先短验证再单组1024步 | 对照纯模型和现K8；若仍无净收益，优先停止前缀统计方向 |
| 2：普通残差MLP容量对照 | 同等附加容量本身是否有用？ | 相近参数量、同插入点与零输出初始化，独立从共同初值训练 | 若MLP优于Fisher，不能把容量收益归因于Fisher；与K1对照回答不同问题 |
| 条件路线：更有区分度的成分初始化 | 当前成分近均匀是否限制收益？ | 固定训练集表示后拟合GMM或数据驱动中心；必须定义投影/骨干固定及共同起点 | 会引入新的数据拟合阶段，先检查分配再训练；不因GMM更复杂就预设更优 |
| 条件路线：有限窗口统计 | 全前缀平均是否稀释近期信息？ | 仅改聚合范围，例如固定32-token因果窗口，重新验证缓存 | 只有前缀统计值得保留时再做；窗口32是预设候选，不是已选最优值 |
| 目标切换：强化纯MiniMind | 若更关注可用语言/对话能力 | 扩大预训练数据，必要时接SFT；若再加Fisher，两组仍需相同共同起点和后续预算 | 不能拿充分训练模型对比当前短预算模型宣称结构优势 |

优先推荐K1，因为它直接回应“8成分分配近均匀”的观测，改动单一、参数和计算更少。
但它同时改变容量，不能单独把结果全部归因于成分数；容量对照是独立问题。
新候选若复用baseline成绩，必须保持其数据、初值、日程、精度和评估协议完全一致，
否则需要重跑匹配baseline。预计新增一个同预算组约20分钟量级，仅为当前实测外推。
若小幅优势出现，再增加至少两个seed；目前无需为不支持的收益立刻重复大量训练。
